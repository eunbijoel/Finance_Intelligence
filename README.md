# Finance Intelligence

[English README](README_EN.md)

국내 기업 **공시·재무(OpenDART)** 와 **사업계획서 등 업로드 문서**를 같이 보고,  
검토 담당자가 쓸 **초안 메모 · 확인 질문 · 위험 신호**를 만들어 주는 도구입니다.

> **중요**  
> 이 SW는 **대출을 자동으로 승인/거절하지 않습니다.**  
> 신용등급·한도·투자 추천도 하지 않습니다.  
> 화면의 「검토 완료」는 **대출 승인**이 아니라,  
> **자료와 검토 메모를 승인 담당자가 확인 완료했다**는 뜻입니다.

---

## 한 줄로 이해하기

**기업 검토를 만들고 → 자료 등록 → AI 검토 → 담당자 확인 → 검토 완료** 흐름의 프로토타입입니다.  
(실제 은행 로그인·전자결재는 없고, 사이드바 **관리 정보**에서 사용자를 고릅니다.)

```
자료 등록 → AI 검토 → 담당자 확인 → 검토 완료
```

## 실행

API 키 없이도 **삼성전자(005930) 샘플**로 돌려 볼 수 있습니다.

```bash
cd finance_intelligence
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py --server.port 8506
```

브라우저: `http://localhost:8506`

### 실행 예

1. 왼쪽 **관리 정보**에서 사용자 **김심사 (검토 담당자)** 선택  
2. **새 기업 검토** → 기업명 `삼성전자`, 금액·용도·상품·기한·승인 담당자 입력 → **기업 검토 시작**  
3. **1단계 자료 등록**에서 `data/sample_business_plan.txt` 업로드 → **AI 검토 시작**  
4. **2단계 AI 검토**에서 중요 / 확인 필요 / 자료 보완을 보고 **검토 의견 작성**  
5. **3단계 담당자 확인**에서 의견 작성 → **승인 담당자에게 전달**  
6. 사용자를 **박책임 (승인 담당자)** 로 바꾼 뒤 **4단계**에서 확인 후 **검토 완료**  
7. **완료된 검토**에서 결과 확인 (변경 이력·이전 분석 비교는 펼쳐서 확인)

실제 공시 데이터를 쓰려면 아래 [설정](#설정-env)에 `DART_API_KEY`를 넣으세요.

## 누가 무엇을 하나?


| 역할 | 할 수 있는 일 | 못 하는 일 |
| ---- | ------------- | ---------- |
| **검토 담당자** (김심사, 이담당) | 자료 업로드, AI 검토, 의견 작성, 승인 담당자에게 전달 | 최종 **검토 완료** |
| **승인 담당자** (박책임) | AI·담당자 의견 비교, 보완 요청, **검토 완료** | (본인 배정 건만) |
| **관리자** | 전체 조회·설정 확인 | — |


같은 사람을 검토 담당자와 승인 담당자로 동시에 지정할 수 없습니다.

## 화면 구성

### 왼쪽 사이드바 (기본 3개)

| 메뉴 | 설명 |
| ---- | ---- |
| **내 검토 업무** | 지금 할 일 · 기한 · 진행 단계 |
| **새 기업 검토** | 기업 검토 생성 후 바로 자료 등록으로 이동 |
| **완료된 검토** | 검토 완료·종결 건 |

하단에 접힌 **관리 정보**: 사용자 전환, 버전, 기업 검색(건 없이)

### 기업 검토 4단계

| 단계 | 하는 일 |
| ---- | ------ |
| **1. 자료 등록** | 사업계획서·재무자료 업로드, AI 검토 시작 |
| **2. AI 검토** | 중요 / 확인 필요 / 자료 보완, 근거 보기, 확인 질문 |
| **3. 담당자 확인** | AI 메모 + 담당자 의견, 승인 담당자에게 전달 |
| **4. 검토 완료** | 승인 담당자 확인 · 보완 요청 또는 검토 완료 |

재무원본·공시·SHA·모델 버전·감사로그 등은 **펼쳐서 보기** / **관리 정보**에 있습니다.

## 주요 기능 요약

- **재무비율·위험 규칙·교차검증** — 없으면 추정하지 않음  
- **문서 해시·중복 탐지** — 백그라운드 저장 (화면에는 기본 숨김)

- **분석 버전 · 감사로그 · 이전 분석 비교**  
- **LLM:** 기본 로컬 Ollama (꺼져 있어도 규칙 기반 분석 동작)

## 설정 (`.env`)

프로젝트 루트에 `.env`를 **직접** 만드세요. Git에 올리지 않습니다.


| 변수 | 설명 |
| ---- | ---- |
| `DART_API_KEY` | [OpenDART](https://opendart.fss.or.kr/) API 키 |
| `LLM_PROVIDER` | `ollama`(기본) 또는 `openai` |
| `OLLAMA_BASE_URL` | Ollama 주소 |
| `LLM_MODEL` | 모델명 (기본 `gemma4:31b`) |
| `LLM_BASE_URL` / `LLM_API_KEY` | openai 사용 시 |
| `FI_MOCK_LLM` | `true`면 LLM 호출 안 함 |
| `FI_DB_PATH` | DB 경로 (비우면 `data/finance_intelligence.db`) |
