# Finance Intelligence

[English README](README_EN.md)

국내 기업 **공시·재무(OpenDART)** 와 **사업계획서 등 업로드 문서**를 같이 보고,  
심사 담당자가 쓸 **초안 메모 · 확인 질문 · 위험 신호**를 만들어 주는 도구입니다.

> **중요**  
> 이 SW는 **대출을 자동으로 승인/거절하지 않습니다.**  
> 신용등급·한도·투자 추천도 하지 않습니다.  
> 화면의 「검토 승인」은 **대출 승인**이 아니라,  
> **검토 자료와 메모를 Checker가 확인 완료했다**는 뜻입니다.

---

## 한 줄로 이해하기

**심사 건을 만들고 → Maker가 분석·의견 작성 → Checker가 검토·승인**하는 프로토타입입니다.  
(실제 은행 로그인·전자결재는 없고, 사이드바에서 사용자를 고르는 방식입니다.)

```
접수 → 자료 검토 → Maker 작성 → Checker 검토 → 검토 승인 → 종결
```

## 실행

API 키 없이도 **삼성전자(005930) 샘플**로 돌려 볼 수 있습니다.

```bash
cd finance_intelligence
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py --server.port 8506
```

브라우저: `http://localhost:8506`

### 실행 예

1. 왼쪽에서 사용자 **김심사 (MAKER)** 선택
2. **새 심사 건 생성** → 기업명 `삼성전자`, Checker·금액·용도·상품·기한 입력
3. 건을 열고 **검토 시작**
4. **기업자료 검토**에서 `data/sample_business_plan.txt` 업로드
5. **Agent Workspace**에서 AI 통합검토 → Maker 의견 쓰고 저장 → Checker 검토 요청
6. 사용자를 **박책임 (CHECKER)** 로 바꾼 뒤, **Checker 검토** 탭에서 확인 후 **검토 승인**
7. **분석·감사 이력**에서 “누가 무엇을 했는지” 확인

실제 공시 데이터를 쓰려면 아래 [설정](#설정-env)에 `DART_API_KEY`를 넣으세요.  
심사 건 없이도, 예전처럼 사이드바 **기업 검색**만으로 조회·분석할 수 있습니다.

## 누가 무엇을 하나?


| 역할                   | 할 수 있는 일                               | 못 하는 일       |
| -------------------- | -------------------------------------- | ------------ |
| **Maker** (김심사, 이담당) | 자료 업로드, AI 분석, 의견 작성, Checker에게 검토 요청  | 최종 **검토 승인** |
| **Checker** (박책임)    | AI 원문 vs Maker 의견 비교, 수정 요청, **검토 승인** | (본인 배정 건만)   |
| **Admin** (관리자)      | 전체 조회·설정 확인                            | —            |


같은 사람을 Maker와 Checker로 동시에 지정할 수 없습니다.

## 자세히

### 기업 검토

“지금 무엇을 보고, 무엇을 더 확인해야 하나?”를 먼저 보여 줍니다.

- 매출·이익·현금흐름·부채 등 **무엇이 달라졌나**
- **왜 중요한가**, **무엇을 확인해야 하나**
- 위험 신호 카드, 재무 차트, 최근 공시


| 종합 상태       | 의미                       |
| ----------- | ------------------------ |
| 분석 전        | 아직 AI 검토 전               |
| 검토상 특이사항 없음 | 규칙상 특이 신호 적음 → **승인 아님** |
| 추가 확인 필요    | 질문·자료 보완 필요              |
| 중요 위험 신호 발견 | 집중 검토 권고 → **거절 아님**     |


### 기업자료 검토

PDF / DOCX / XLSX / CSV / TXT 업로드.  
자금 용도, 매출 전망, 상환 계획 등을 뽑고, 가능하면 **근거 위치**(페이지·시트 등)를 남깁니다.  
같은 파일이라도 내용이 바뀌면 새 버전으로 저장되고, 완전히 같은 파일은 중복으로 알려 줍니다.

샘플: `data/sample_business_plan.txt`

### Agent Workspace

DART 재무 + 문서를 단계적으로 분석 → 메모·교차검증·위험 신호 표시.  
근거가 부족하면 억지로 결론 내지 않고 멈춥니다.  
저장 시 **AI 원문**과 **Maker 의견**을 따로 남깁니다.

### Checker 검토 · 감사 이력

- AI가 쓴 글 / Maker가 고친 글 / 차이 비교  
- 승인 전 체크박스 3개 필수 (금융 자동 판단 아님 등)  
- 누가 언제 무엇을 했는지 **감사로그** (수정·삭제 불가)  
- 과거 분석 **재현**: 당시 문서·버전과 지금을 비교 (LLM 문장이 똑같지는 않을 수 있음)

## 주요 기능 요약

- **재무비율:** 부채비율, 유동비율, 이익률 등 — 없으면 추정하지 않고 「계산 불가」
- **위험 규칙:** 영업CF 2년 음수, 부채 급증, 계획과 공시 불일치 등 (`config.py`에서 임계값 조정)
- **분석 저장:** SQLite에 버전별로 쌓임 (덮어쓰지 않음)
- **LLM:** 기본 로컬 Ollama. 꺼져 있어도 규칙 기반 분석은 동작

## 설정 (`.env`)

프로젝트 루트에 `.env`를 **직접** 만드세요. Git에 올리지 않습니다.


| 변수                             | 설명                                            |
| ------------------------------ | --------------------------------------------- |
| `DART_API_KEY`                 | [OpenDART](https://opendart.fss.or.kr/) API 키 |
| `LLM_PROVIDER`                 | `ollama`(기본) 또는 `openai`                      |
| `OLLAMA_BASE_URL`              | Ollama 주소                                     |
| `LLM_MODEL`                    | 모델명 (기본 `gemma4:31b`)                         |
| `LLM_BASE_URL` / `LLM_API_KEY` | openai 사용 시                                   |
| `FI_MOCK_LLM`                  | `true`면 LLM 호출 안 함                            |
| `FI_DB_PATH`                   | DB 경로 (비우면 `data/finance_intelligence.db`)    |

## 알아두면 좋은 점

- 진짜 로그인(SSO)·전자결재·내부망 연동은 **없습니다** (연습용 사용자 선택)
- 공시 **본문 PDF를 깊게 파싱**하지는 않습니다 (목록·링크 중심)
- 최종 금융 판단은 항상 **사람**이 합니다
- 분석 재현은 “같은 조건인지 확인”에 가깝고, AI 문장이 100% 같지는 않을 수 있습니다
